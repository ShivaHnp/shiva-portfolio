# Shiva Hassanpour — Personal Portfolio

Personal portfolio site built from scratch with React, TypeScript, and Tailwind CSS. Designed to showcase my projects and skills as a frontend developer.

🔗 Live site: [shivahassanpour.dev](https://shivahassanpour.dev)

## Tech Stack

- **React** — component-based UI
- **TypeScript** — type-safe development
- **Tailwind CSS** — utility-first styling
- **Vite** — build tool and dev server
- **Vercel** — deployment with custom domain

## Features

- Fully responsive design across all screen sizes
- Project showcase with live links and source code
- Clean, minimal UI with attention to performance
- Custom domain configured via Vercel

## Getting Started

```bash
git clone https://github.com/ShivaHnp/shiva-portfolio
cd shiva-portfolio
npm install
npm run dev
```
